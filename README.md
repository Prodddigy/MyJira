# MyJira: Java Ticket Management System

A command-line ticket management application written in Java. The project is designed to provide a simple way to organize projects and manage their associated tickets through an interactive CLI.

This project is meant to be for fun. An opportunity to learn something new.

## Features

The following features are currently implemented:

- **Project selection** – choose a project to work with.
- **Ticket creation** – create new tickets and provide their details.
- **Ticket listing** – display tickets belonging to the currently selected project in a compact, readable format.
